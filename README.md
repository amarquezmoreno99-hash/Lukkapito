# Asistente de Proyectos

Aplicación web interna para registrar proyectos de cliente, generar actas de reunión con IA, gestionar to-do's y cerrar proyectos.

> Documento provisional. La guía completa (configuración de Supabase, secretos, despliegue en GitHub Pages, alta de usuarios y limitaciones) se añadirá en la fase final.

## Ver la aplicación en local

La app no necesita compilación. Desde la carpeta del proyecto:

```bash
python3 -m http.server 8000
```

y abre http://localhost:8000 en el navegador.
